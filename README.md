# SignCourse Studio · 手语课程编排工具

SignCourse Studio 是面向手语教师的课程设计工作台。教研组长在**共享课程库**里维护标准课程并发布版本，老师从库里**取一份到自己名下**编排学习步骤；改好的步骤可以**申请回灌**到库里。教师可以把示范片段、手形说明、字幕、镜头角度、常见错误和练习任务组合为学习步骤，并在手机和平板预览中检查字幕安全区、步骤依赖和替代文本。

## 共享课程库 / 个人课程

- **两种归属、两条边界**：共享课程库的标准课程只由教研组长维护和发布；老师只能编辑自己名下的副本。老师越权改库、或改动他人/组长名下的课程都会被拦下（只读）。
- **取课**：老师对已发布的标准课程「取一份到我名下」，每个学习步骤都带来源与状态（未改动 / 我改过 / 自建 / 两版冲突 / 库已删）。
- **版本升级三向合并**：组长发布库的新版本后，老师副本里**没动过的步骤立即跟着升级**；两边都改过的步骤**不会被悄悄替换**，而是把两版内容并排摆出，列出差异字段，由老师自己「采用库新版本」或「保留我的版本」。库里删除的步骤：未改动的随升级移除，老师改过的会保留并请老师裁定去留。
- **回灌申请**：老师把改好或新增的步骤申请补回课程库。系统**按学习步骤逐项补录**，每项独立结算——某项结构失败（如库步骤已被删除）不影响其余步骤；失败的申请会**留住**，课程库恢复在线后自动逐项补上，也可手动重试。已成功回灌的内容不会重复提交。
- **课程库故障演练**：顶栏可一键模拟课程库不可用。故障期间取课、发布、回灌暂停，但个人课程仍可在本地继续编排；恢复后挂起的回灌自动补录。
- **旧数据迁移**：打开时若检测到旧的单人本地稿（`sologsb-1012-sign-course-project-v1`），会自动按归属拆分——课程进共享课程库（冻结版本作为历史版本、当前稿发布为首版），原老师的稿件迁为其名下个人副本，随后删除旧 key。

## 功能

- 课程模块：创建多个模块，维护模块目标、主题色和学习步骤。
- 步骤编排：每个步骤支持示范、讲解、练习类型，以及时长和入门/进阶/挑战难度标签。
- 动作素材：记录示范片段名称、可选的本地素材地址、手形说明、主要动作区域和镜头角度。
- 字幕与无障碍：设置字幕文本、字幕位置和替代文本，并在预览中标记字幕与动作区域冲突。
- 学习依赖：选择前置步骤，检查前置项不存在或指向后续步骤的跳级问题。
- 练习设计：记录练习任务、反馈方式和常见错误清单。
- 设备预览：在手机 9:16 和平板 4:3 视图间切换，并运行带检查点的动作时间线。
- 发布前检查：检查字幕遮挡、步骤跳级、替代文本缺失、练习反馈不完整和常见错误缺失。
- 本地工作区：共享课程库、个人副本、回灌队列与身份都保存在 `localStorage`（`sologsb-1012-workspace-v2`）；浏览器离线或刷新后可继续编辑。顶栏可在「教研组长 / 陈老师 / 周老师」身份间切换以体验不同权限。
- 键盘操作：`Alt + ↑/↓` 调整步骤顺序、`⌘/Ctrl + S` 查看保存状态。

## 技术栈

- Stencil 4
- TypeScript 5
- Ionic 9
- Ionic Core CSS

## 目录

- `src/models.ts`：共享库课程、版本、个人副本（步骤状态）、回灌申请等数据模型与校验。
- `src/services/library.ts`：纯逻辑——取课、三向合并升级、冲突裁定、逐项回灌合并。
- `src/services/studio-store.ts`：本地持久化工作区、角色鉴权、离线队列、v1 旧稿迁移。
- `scripts/verify.ts`：核心流程的端到端逻辑验证（43 项断言）。

## 开发

```bash
npm install
npm run dev
```

Stencil 开发服务器默认监听 `3333` 端口，并启用监听构建。

## 构建

```bash
npm run build
```

生产静态文件输出到 `www/`。构建会同时生成 Stencil 分发包和组件文档。

## 逻辑验证

```bash
node scripts/run-ts.cjs scripts/verify.ts
```

覆盖：旧稿迁移、越权拦截、未改动步骤自动升级、改动步骤两版冲突与裁定、库删除的去留、回灌失败留住与恢复后逐项补录、回灌内容随发布对齐等。

## Docker

```bash
docker build -t sologsb-1012 .
docker run --rm -p 10012:80 sologsb-1012
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10012`。
